# موقع جمعية تيسير النسك

نموذج أولي للموقع الإلكتروني لجمعية تيسير النسك (جمعية أهلية تحت التأسيس، مقرها مدينة الرياض).

- موقع ثابت (HTML/CSS/JS) يعمل دون خادم، ويُنشر عبر GitHub Pages.
- الصفحات: الرئيسية، من نحن، الحوكمة والشفافية، البرامج، الشراكات، التطوع، تواصل معنا، البحث.
- `docs/` اللوائح والسياسات المعتمدة (PDF)، و`kits/` الحقائب التعريفية للبرامج.
- النماذج للعرض فقط حتى تُربط ببريد الجمعية.
